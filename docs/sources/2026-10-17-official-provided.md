# 「イノベーターになろう」

## *イノベーターを目指す学生向け日本最大のハックイベント*

JPHACKS（ジャパンハックス）は、学生を対象にした日本最大規模のハックイベントで、2014年より全国の複数都市で開催されています。

開催13周年を迎える2026年は、全国9拠点10会場にて開催します。

オンラインでの事前勉強会（ハッカソンに向けたアイデア創出ワーク）を経て、オフライン予選である「Hack Day（ハックデイ）」をA日程・B日程に分けて実施します。

予選を通過した15チームは、東京大学にて一同に会し本選である「Award Day（アワードデイ）」でピッチを行います。Award DayではJPHACKS Innovator認定のほか、様々な賞を用意しています。

皆さんの新しい未来を共に切り拓きましょう！

# 全体の流れ

JPHACKS2026の全体スケジュール及び、イベントの流れは以下のようになっております。

# [前半]Hack Dayの部

プレエントリーからHack Day参加までの流れです。Learning Dayは参加を推奨する事前学習期間（オンライン）です。Hack DayはA日程・B日程に分けて実施し、いずれも**オフライン参加が必須**となります。

また、Hack DayはA日程・B日程の2日程で開催します。参加を希望する拠点がどちらの日程で開催するかをよくご確認のうえ、エントリーしてください。

※Hack Day会場までの交通費支給はございません。あらかじめご了承ください。

Hack Day終了後、各会場の発表内容をオンライン審査し、Award Day進出チーム（15~16チーム）を決定します。進出チームには審査委員からのフィードバックをもとに、オンラインでの追加開発期間（Kaizen Sprint）を用意します。

# **1. プレエントリー/本エントリー**

## 1-1. プレエントリー(参加者全員）

### JPHACKSのWebサイトから、参加希望会場のフォームよりプレエントリーを完了させてください

- プレエントリーが完了した方には本エントリーのご案内メールを差し上げます
- プレエントリーは **参加を予定される方全員の記入が必須** となっておりますので、チーム参加の方も必ずチームメンバー全員が完了させるようにしてください
- プレエントリーだけでは、 **参加が確定しておりません** ので、ご注意ください

## 1-2. 本エントリー（チーム登録）

- プレエントリーが完了した方には、運営事務局より本エントリーフォームをお送りいたします
- 本エントリーフォームは個人参加用フォームと、チーム参加用フォームの二種類があります。
- チームでの参加をご希望の場合はチームの代表者1名が本エントリーを行ってください。

※個人参加とは、事前にチームを組まず、運営が編成したチームでハッカソンに参加することを指します。JPHACKSでは必ず2名以上でチームを組んで参加いただく必要があります。

# 6.  10月30日(金)～11月14日(土)：Kaizen Sprint

## 6-1. 10月26日(月) AM8:00：**オンライン審査**

Hack Dayにて提出されたプロダクトの中から、審査委員会にてオンライン審査を実施し、合計15チームのAward Day進出チームを決定致します。選出されたチームは、Award Dayに参加する権利が得られます。**審査はA日程は10月19日（月）AM8:00、B日程は10月26日(月)AM8:00から行われるため、審査が開始されるまでは提出したGitHubや動画を含む提出物の更新が可能です。**

## 6-2. 10月30日(金) 18:30〜20:00：FinalistDay(Award Day進出チームの発表)＠オンライン

Hack Day（予選）の審査結果と、最終成果発表イベント「Award Day」へ進むチームを、オンラインで発表します。

AwardDayでのピッチや展示会に向けて、各チームがプロダクトの改善を行う期間です。Award Day進出チームには、審査委員からのフィードバックをお送りいたしますので、それを基に改善を行っていただきます。

# 7**. 11月15日(日)：JPHACKS Award Day**

### 進出**チームによるピッチと展示、Innovator認定および各賞の授与**

Award Dayに進出したチームは、東京大学**・伊藤謝恩ホール**にて、最終成果発表をオフラインにて実施します。

最終的に残った15チームが全体でのピッチ(8分)を行います。 また、発表後は展示ブースを設け、作品の紹介を会場の皆さんの前で実施します。 

その後、組織委員会・審査委員会審査による**JPHACKS Innovator認定**チームを発表。更には最もオーディエンスから投票を得たチームに贈られる **Best Audience Award**、審査委員会・組織委員会によって最も優れた作品として選ばれる **Best Hack Award**を授与いたします。また、JPHACKS参加チーム全チームを対象とした、各スポンサーから贈られる**Sponsor Award**の発表をおこないます。

表彰後は、スポンサー、共催の方々、参加者全てが参加する懇談会を開催いたします。懇談を通じて、より多くの出会いや機会創出につなげることを目的としております。

また、惜しくもAward Day進出を逃したHack Day参加者の皆さんも、最終ピッチの観覧が可能です。

# お問い合わせ方法

お問い合わせは以下の連絡先までよろしくお願い致します。

1. [Slack](https://slack.com/)
目的
JPHACKSでは、全国9拠点10会場、合計400名を超えるハッカソンの参加者の方々に対し、公平に情報を配信する事を目的として、Slack（チャットサービス）を導入しております。
利用用途
- チームグループの作成 
  - 個人参加の場合であった際も、事前にチームとコミュニケーションを取ることが出来ます。当日までのやりとりにご活用ください。
- 運営からのご案内 
  - 全体への案内用のチャンネルを作成し、皆様への必要情報を配信していきます。
- 質疑応答 
  - 質疑応答用のチャンネルを作成し、参加者の皆様から、ハッカソン内での不明点や、プロダクトの提出についてなど、お問い合わせに対応いたします。
- API・外部ツールのお問い合わせ 
  - API等、外部ツールに関する問い合わせ用チャンネルを用意し、各プロダクトを提供してくださっている方に利用方法についてなどの質疑が出来るように致します。
導入方法
1. 招待メールの確認・グループ承認
2. エントリにご登録いただいたメールアドレス宛に、"[jphacks2025.slack.com](http://jphacks2025.slack.com)"より招待が届きます。メールをご確認いただき、アカウントの作成及びチームへの参加を承認していただきます。
3. アカウント作成時に、アカウントがエントリー時のメールアドレスになっているかを必ずご確認ください
4. チャンネルの確認・運営からのメッセージの講読
5. エントリー締め切り後、運営局より各チームごとのプライベートグループを作成いたします。このグループはチーム内で自由に使用することが可能です。その他、運営局が発信をしているチャンネルに参加をしていただくことができ、随時運営局からの情報を受け取ったり、問い合わせをすることが可能です。
設定
1. Slackアカウントが作成できたら、自分の表示名を変更しましょう。 
  1. 左下の自分のアイコン→「プロフィール」→名前部分の「編集」→「氏名_チームID」に変更してください
  2. チームIDは、ご自身が所属しているチームチャンネル名(アルファベット二文字(会場ID)＋数字4桁)です。
  3. 例：坂井和佳奈_kz2500, 日本太郎_tk_a_2501
2. Slackでは重要なお知らせを頻繁に行います。通知設定をすることで、確実に連絡が受け取れるようにしてください。 
  1. 左下の自分のアイコン→「環境設定」→「通知」→「通知のタイミング」を「ダイレクトメッセージ＆メンション＆キーワード」に設定（自身に関係のある通知のみが届くようになります）
注意事項
- JPHACKSに関連する事項以外での目的のご利用はご遠慮ください。
- 投稿内容に合ったチャンネルを使い、相手を尊重して発言してください。
- APIキー、パスワード、未公開のアイデアやソースコードはオープンチャンネルには投稿しないでください。
- 他のチームの成果物や投稿を、許可なく外部へ共有しないでください。
- 営業・勧誘、誹謗中傷、迷惑行為は禁止します。
- 困ったことや不適切な投稿を見つけた場合は、運営へご連絡ください。
2. [GitHub](https://github.com/)
目的
JPHACKSでは、技術審査・プロダクト情報提出のために、参加者の皆様にGitHubの使用をお願いしています。

1. [github.com](https://github.com/)にアクセスし、アカウントを作成。
2. 本エントリ時に運営事務局へのアカウントを共有（代表者のみ）

“X-Tech 2026”  ～ Full Stack Hackers ～
AI(人工知能)は、JPHACKSに参加するみなさんが挑戦するHackingにも劇的な進化をもたらしています。これを、一番自分事として感じているのが、参加を考えている学生ハッカーのみなさんではないでしょうか。 いろいろな難しい/面倒な質問に答えてくれるAIは、みなさんの日々の生活だけではなく、ハッキングにおいても、力強い・優しい・たのもしい、かつ忖度までしてくれるバディー(仲間)になっていることでしょう。 しかし、人という仲間での活動でしたか実現できない”創造”が存在し、それがAIの時代であるからこそ重要であるということも認識されています。
もう一つ、”AIが” 我々に、そしてみなさん、さらに人類に求めているものが、上から下まで(さらに右端から左端まで)の**“フルスタック(Full Stack)”**での経験・知見そしてハッキング能力のようです。超大規模データセンターで稼働するAIサーバ群、我々の目の前で動作するPhysical AIロボット(ソフトウェアロボットとハードウェアロボットの両方)には、ハードウェアからソフトウェアまで、すべてのスタックが要求されています。
もう一つのフルスタックは、これまでの新しい社会には存在しなかった創造的なアプリケーションです。これも、これまでの社会知識には詳しいAIには、とても不得意な分野になります。
Ｘ-Techの Ｘは Crossで、以下のようなハッキングを期待していました。
学生諸君の柔らかい発想で，デジタル技術と”面白い何か”を掛け合わせて，新しい未来(future)を産み出す可能性を持つクリエイティブなアイデアを産み出し，それをチームでそしてみんなで力を合わせてクールで“本当に(Real)”形のあるものに変貌(Transform together)させ，我々や社会，そして未来を魅了せてくれる“刺激”そして”Real Impact”の芽が絞り出されることを期待しています．みんなで手を取り合って，次の社会の進化にインパクトを与えるようなInnovatorとなる可能性を探りましょう．
はい、横方向(右端から左端)の“掛け算” でした。JPHACKS2026では、AIがわれわれに要求している**「縦方向(上から下まで)の“掛け算”」**への注目とアイデア・実装を期待しています。 AIにはできない、柔らかい発想で、新しい未来(Future)を産み出す可能性を持った創造的なアイデアをチームで産み出し、そして、力を合わせてクールで形のある“フルスタック”のものを創り出して、われわれだけではなく、社会、そして未来を魅了させてくれる”刺激の芽”が絞り出されることを期待しています。みんなで、手を取り合って、次の社会、そしてAIにも、進化にインパクトを与えるようなInnovatorsを産み出すは可能性を探りましょう。
掛け算(X: Cross)する相手は何でも構いません。 例えば、過去の X-Techで受賞したプロダクトは、
- AshiArt： ランニングコースをアートに !!
- 4DX@HOME: おうちで4DXを体験する !!
- ゆびサッカー： 指をつかった「直観的な操作性」のサッカーゲーム
- CriCube： 折り紙の折り方を教えます
- 革靴メンテなんです !!
- Kanpai ！
- あんしん夜道
- 赤ちゃんを持つ若い親戚の母を助ける「あのね」
- 友人の視覚障害者を支援するスマート白杖Walky
- ダンス表現を自在にショーアップするGROOVE
などなど、学生のみなさんの自由でクールな**(AIにはできない)**発想を期待しています。

JPHACKS 2020/2021は コロナウィルスと人類の闘いの中、“学生諸君のハッキング活動を「自粛しない！」、「もとに戻さない(退化させない)！」”を合言葉に、完全デジタル”での開催し、JPHACKS2022から対面での開催に復帰しました。2020年以前のJPHACKSとは明らかに異なるオンラインとオフラインが融合した新しい学生の皆さん間でのコラボが発現し、お互いがInspire され、新しい(Transformed) JPHACKS の AWARD DAYを産み出しました．さらに、2024年は，JPHACKSの次の10年の幕開けとして，基本的に対面でのハッカソンに回帰, 実物理空間・時間空間を参加者間で共有し, 実空間・実社会に“Real”なインパクト(Impact)を創成するアイデアや実装への挑戦の“Next Decade”、そして”Future”への”Real Impact”の起動の年としました。昨年2025年は、”Live Real. Hack the Future”として、実物としてのハッキングを目指しました。そして、2026年は、JPHACKSにとっての、AIとの共存の元年とも捉え、AIと共存するHackerを目指すという思いも込めて、
Full Stack Hackers
としました。
日本最大級の学生ハッカソンであるJPHACKSは，企業が主導する課題解決型のハッカソン，個別の大学が主導する教育型のハッカソンとは異なり，大学と企業の垣根を超え，かつ世界・グローバルな展開を意識した“学生が主役”のハッカソンを目指すメインミッションは，１ビットも変わっていません． 共にアイデアを洗練し実装するローカルなチーム(＝ユニークで多様な特技を持った”個人”の集まり)の新しい“Real”での結束・団結・協力の醸成と爆発力を期待しています． 一般のハッカソンでは具体的テーマがハッカソン会場で提示されることが少なくありませんが，JPHACKSは学生諸君に，じっくりと準備・議論をできる時間的な余裕を与えることで，より「深い」内容のアイデアや作品を生み出すことを期待することは，今回もぶれず変えません．
スポンサー企業の皆様が，それぞれ独自の異なった視点でJPHACKS参加チームの協調作業とアウトプットを評価されることもあり，JPHACKSの評価軸は非常にかつ常に多様なものとなります．未来の創造に必須となる多様性の尊重です．
このように，JPHACKSは「無差別級」の学生ハッカソンであり，学生諸君の今後の多様でイノベーティブな活躍を促進・応援することを目標としています．企業の枠を越え，未来を創造するイノベータを，“未来のために“ 応援しませんか．

成果物(作成するプロダクト)の概要
JPHACKS出場チーム（以下、参加者）が本イベントで創作・開発する成果物（以下、成果物）とは、本イベント内で与えられた期間中に参加者によって制作されるハードウェア及びソフトウェア（プログラムソースコード）の事を指します。
JPHACKSにおける事前準備・事前開発について
JPHACKSでは限られた開発時間の中でより質の高いプロダクトを開発していただくために、事前開発や持ち込みなどをおこなっていただくことが可能です。ただし審査においてはあくまでJPHACKS開発期間内での開発物が評価の対象となります。
参加者が持ち込む素材、プロダクト等について
1. 参加者は、JPHACKS組織委員会（以下、運営事務局）及びJPHACKSにスポンサーしている企業（以下、スポンサー企業）が用意する以外の、一般に全ての参加者が手に入れることが可能である公開されているデータ、ソフトウェア、ハードウェア、API、ライブラリ、及びコンテンツ等（以下「参加者のプロダクト」といいます）を本イベントに持ち込み、利用することができます。ただし、参加者のプロダクトの購入費用等は、参加者の自己負担とします。
2. 参加者は、参加者のプロダクトを自己の責任において用いるものとします。参加者のプロダクトが第三者の知的財産権を侵害したとして運営事務局がクレームを受けた場合、当該プロダクトを持ち込んだ参加者がこれを解決するものとします。
3. 本イベントで使用するPC及び開発環境は、参加者自身が用意するものとします。「機材が故障した」「充電アダプターを忘れた」等のトラブルが起きた際も、各開催場所での貸し出し等はできませんので、あらかじめご了承ください。

3. 第三者の著作権や知的財産権その他の権利を侵害する行為。
4. 公序良俗に反する成果物の開発行為。

チーム内で顔合わせ・アイデア出しをする
- Slack上のハドルミーティング、チャット等を活用しながら、当日までに顔合わせや作ってみたいプロダクトのアイデア出しをしておくことをお勧めします

- 拠点ごとにスポンサー賞が用意されているので、スポンサー賞の条件を確認し、「どの賞を狙うか」の作戦を練るのもお勧めです。
Hack Day当日の流れ
【Day1】
- 各拠点チャンネルで共有される会場情報を確認のうえ、元気に会場に来る 
  - 会場によっては飲食店やコンビニ等が周りにない場合もあるため、必ず確認してください
  - 遅刻・欠席は、必ず各拠点チャンネルで運営をメンションしてご連絡ください、
- 会場受付を済ませたら、指定された座席に着席する
- 全体ガイダンスを受ける
- 開発開始
- 終了時間になったら運営からのアナウンスを聞いて、解散
【Day2】
- 集合時間までに会場に到着。
- 簡単なアナウンスを聞いた後、引き続き実装開始。
- code freeze後の15:30までに、作品提出フォームを提出する 
  - 作品提出フォームは、スポンサー企業がスポンサー賞を授与するチームを決めるために使用します。
  - 作品提出フォームの項目 
    - チーム情報
    - 製品情報リンク(製品情報が掲載されたGitHubリポジトリのURL)
    - アップロードした製品説明動画のURL
    - 製品名
    - 開発したプロダクトの ○○ x Tech、製品概要、審査委員へのアピール
    - 希望スポンサー賞、スポンサー提供物の利用有無
    - 製品の自己評価
    - AwardDayに関する質問
    - チームを表す写真1枚 
      - ※集合写真や、実際にプロダクトを使用している様子だと👌
      - JPHACKS広報や、結果発表動画などに使用します。
- 開発と並行して、最終成果発表の接続チェックやプレゼンテーション資料作成を行う
- Code freeze(開発終了)
- 最終発表・デモを行う 
  - GoogleMeetに接続し、画面録画をしながら行います。(後ほど審査委員が録画を見て審査をするため)
  - 発表の中にはプロダクトデモを含むようにしてください。

  - Award Day進出者の発表は、Hack Day終了後の審査委員による審査を経て、後日発表されます
  - A日程のAwardDay審査は10/19（月）8:00、B日程は10/26（月）8:00より行われます。
