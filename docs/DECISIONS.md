## 判断を追記する雛形

```markdown
### Dxxx: 判断の見出し

- 日付・決定者:
- 状態: 提案 / 採用 / 保留 / 廃止・置換
- 解く問題:
- 判断:
- 根拠・出典・実機確認:
- 検討した選択肢:
- 理由と制約:
- 影響する文書・コード:
- 置き換える判断ID（あれば）:
```

既存の記録を削除して過去の合意を消さず、変更時は置換先を追加します。AIだけで新たな仕様を決めた場合は、ユーザーから明確な委任があるかを確認し、単なる実装上の選択とチームの製品方針を区別してください。
