# 共有ドキュメントの案内

人間は [README.team.md](../README.team.md)、開発AIは [AGENTS.md](../AGENTS.md) から読んでください。

| ファイル | 役割 | 更新する場面 |
| --- | --- | --- |
| [AI_CONTEXT.md](AI_CONTEXT.md) | プロダクトの目的、確定事項、候補、受入条件 | スコープ・ターゲット・仕様の変更 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 技術確認、設計案、連携・状態・検証 | 技術選定、API検証、実装の確定 |
| [UI_UX.md](UI_UX.md) | Figma基準画面、文言・遷移、対話UX・プロンプト、実装への引き継ぎ | UI・会話の検討、両班の仕様すり合わせ |
| [HACKATHON.md](HACKATHON.md) | 審査・賞・期限・提出物と矛盾の扱い | 運営からの案内・確認結果 |
| [STATUS.md](STATUS.md) | 実装の現在地、担当、課題、次の一手 | 作業開始・終了・引き継ぎ |
| [DECISIONS.md](DECISIONS.md) | チームの決定とその根拠 | 判断を採用・変更したとき |
| [WORKFLOW.md](WORKFLOW.md) | 共同開発と文書更新の手順、雛形 | 運用の変更 |
| [sources/README.md](sources/README.md) | 出典の状態、原文の場所、参照先 | 新しい資料の受領・確認 |
| [sources/manifest.json](sources/manifest.json) | 原文のハッシュと抽出元範囲 | 新規スナップショット追加時 |

この構成では、原文を保存する層、そこから事実を整理する層、設計・作業の層を分けています。公式原文に設計案を混ぜず、AIが提案を確定仕様と誤読しないよう、各資料に状態と出典を残してください。
